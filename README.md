# 🐈‍⬛ SD Gateway API

Высокопроизводительный асинхронный шлюз для Stable Diffusion Forge. 
Архитектура, одобренная Барсиком.

## 🎯 Философия проекта
**«Нарисовали → Отдали → Забыли»**
Никакого засорения SSD, никаких тяжелых баз данных для хранения картинок. 
Изображения живут только в оперативной памяти Redis строго ограниченное время (TTL), 
после чего бесследно исчезают, оставляя диск чистым для важных вещей (например, для Вискаса).

## 🏗️ Архитектура
Проект разделен на четкие слои ответственности:
- `main.py`: Тонкий слой маршрутизации FastAPI.
- `queue_manager.py`: Управление очередью Redis с защитой от "гонки TTL" и переполнения RAM.
- `forge_client.py`: Асинхронный (`httpx`) клиент для общения с локальным SD Forge.
- `config.py`: Централизованное управление настройками через `.env`.

### 🔥 Ключевые фичи:
1. **Асинхронная очередь:** Боты не блокируются, пока Forge генерирует изображение.
2. **Безопасный TTL:** Время жизни задачи продлевается при каждом изменении статуса. Если задача зависла, она самоуничтожается, не съедая оперативную память.
3. **Zero Disk I/O:** Картинки передаются в base64 и никогда не сохраняются на диск шлюза.
4. **Кросс-платформенность:** Разрабатывается на Ubuntu, развертывается на Windows (или наоборот) без изменения кода, только через `.env`.

## 🚀 Быстрый старт

### 1. Требования
- Python 3.10+
- Docker & Docker Compose (для Redis)
- Запущенный локальный экземпляр Stable Diffusion Forge

```bash
# Клонируем репозиторий (или копируем файлы)
cd sd_forge_queue

# Создаем виртуальное окружение
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate   # Windows

# Устанавливаем зависимости
pip install -r requirements.txt
